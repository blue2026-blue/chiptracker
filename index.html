▶ 單股查詢

🔥 雙軌強訊號
法人（外資/投信）買超 ＋ 集保大戶持股週增 ≥1%，兩個指標同時亮起。這是最可靠的進場前置訊號，代表內外資同步看好。
📡 三大法人（每日即時）
本 App 直接從「台灣證交所」及「櫃買中心」官方 API 抓取當日法人買賣超資料，完全免費、即時、準確。收盤後約 30 分鐘可取得當日數據。
🗄 集保大戶持股（每週）
千張以上大股東真實持股比例。每週五更新，反映上週最後交易日狀況。週增 ≥1% 是有意義的訊號，連增 3 週以上最為強力。這個資料最難造假。
📊 雙軌比對
法人買超＋大戶增持 → 🔥 最強，跟進機率最高
法人買超＋大戶持平 → 👀 短線資金，需觀察
法人賣超＋大戶增持 → 💡 大戶逢低吃貨，中長線機會
法人賣超＋大戶減持 → ❌ 全面出場，暫時迴避
📱 如何使用
1. 掃描頁設定條件 → 完整掃描 → 找出雙軌標的
2. 點「加入追蹤」→ 首頁追蹤清單
3. 每週五從 CMoney 更新大戶持股數字
4. 每日點「⟳ 更新」抓取最新法人資料
5. 雙軌同時亮起時，搭配技術面確認進場
